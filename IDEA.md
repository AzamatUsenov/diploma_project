# Идея дипломного проекта

## Тема проекта
**JobPlatform** — платформа для поиска работы с фокусом на справедливые требования для джуниоров и стажёров

## Основная идея
Платформа для поиска работы, которая решает проблему завышенных требований на Junior-вакансии. HR-менеджеры публикуют вакансии, а соискатели могут откликаться, проходить тесты навыков и получать объективную оценку соответствия. Система анализирует вакансии на адекватность требований и помогает джуниорам находить подходящие позиции.

## Ключевые механизмы
- **Тесты навыков** — объективная метрика вместо "требуется 3 года опыта"
- **Анализ вакансий** — система оценивает адекватность требований для заявленного уровня
- **Матчинг** — сопоставление навыков соискателя с требованиями вакансии
- **Отзывы о компаниях** — прозрачность для соискателей

## Вдохновение
Проблема завышенных требований на Junior-вакансии: просьба 2-3 лет опыта, знание 10+ технологий для стажировки, нереалистичные ожидания от начинающих специалистов.

## Целевая аудитория
- **Соискатели** (особенно джуниоры и стажёры) — поиск адекватных вакансий
- **HR-менеджеры** — публикация вакансий, управление откликами, тестирование кандидатов

## Технологический стек
- **Backend**: Django 4.2 + Django REST Framework + PostgreSQL
- **Frontend**: Flutter (мобильное приложение, кроссплатформенное)
- **Аутентификация**: JWT (SimpleJWT)
- **Документация API**: drf-spectacular (Swagger/ReDoc)
