# Информация о дипломном проекте

## 1. Тип проекта
- **Backend**: REST API на Django + Django REST Framework
- **Frontend**: Мобильное кроссплатформенное приложение на Flutter
- **Веб-интерфейс**: HTML-шаблоны Django (дополнительно)

## 2. Функциональность

### Реализовано:
- Регистрация и авторизация (JWT) с ролями: соискатель / HR
- Профили пользователей (резюме, навыки, портфолио)
- Вакансии: CRUD, фильтрация по уровню/зарплате/навыкам, избранное
- Отклики на вакансии с workflow статусов (pending → reviewed → interview → accepted/rejected)
- Чат между соискателем и HR в рамках отклика
- Система тестов навыков (квизы с вопросами и вариантами ответов)
- Аналитика: анализ вакансий, матчинг навыков, сравнение вакансий
- Отзывы о компаниях (рейтинг, модерация)
- Уведомления (новый отклик, смена статуса, новое сообщение)
- Тёмная тема, онбординг, локализация (русский)
- PDF-отчёты по анализу вакансий

### Модули backend:
| Модуль | Описание |

## 3. Технологический стек

| Компонент | Технология |
|-----------|------------|
| Backend | Python 3.9+, Django 4.2, DRF 3.14 |
| Database | PostgreSQL 14+ (SQLite для dev) |
| Auth | djangorestframework-simplejwt (JWT) |
| API Docs | drf-spectacular (Swagger + ReDoc) |
| Frontend | Flutter 3.9+, Dart ^3.9.2 |
| PDF | xhtml2pdf |
| Deploy | Docker, Gunicorn |

## 4. Данные

- Пользователи и профили (навыки, опыт, образование, резюме-файл)
- Вакансии (требования, зарплата, уровень, навыки)
- Отклики (статус, cover letter, сообщения)
- Тесты (вопросы, варианты, результаты)
- Отзывы (рейтинг, текст, модерация)
- Уведомления
- Избранные вакансии

## 5. Текущее состояние
- **Готовность**: ~90%
- REST API полностью реализован
- Flutter-приложение работает (все основные экраны)
- Тесты написаны для всех модулей
- Seed data для демонстрации (15 пользователей, 20 вакансий, 10 тестов)
- Веб-интерфейс (Django templates) как дополнение

## 6. Безопасность
- JWT-аутентификация с refresh-токенами
- Permission classes для разграничения доступа (HR / соискатель)
- CORS настроен через django-cors-headers
- CSRF protection для веб-интерфейса
- Валидация входных данных на уровне serializers
