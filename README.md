# Дипломный проект

Директория для хранения всей информации о дипломном проекте.

## Файлы

- **IDEA.md** — описание идеи и темы проекта (начните отсюда)
- **PROJECT_INFO.md** — детальная информация про требования, технологии, сроки и т.д.

## Начало работы

1. Заполните `IDEA.md` с описанием вашей идеи
2. Заполните `PROJECT_INFO.md` с детальной информацией
3. После этого можно начинать разработку
